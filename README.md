Online Retail Sales Analysis

Анализ продаж интернет-магазина на основе датасета Online Retail.

Цель проекта

Исследовать динамику выручки, определить наиболее успешные товары и рынки сбыта, изучить средний чек и повторные покупки.

Инструменты

Python

Pandas

Matplotlib

Excel

Основные результаты
