# Анализ продаж Online Retail

## О проекте

Проект посвящен исследованию продаж интернет-магазина за период с 1 декабря 2010 года по 9 декабря 2011 года.

В ходе анализа изучены динамика выручки, наиболее прибыльные товары, география продаж и поведение покупателей.

## Инструменты

- Python
- Pandas
- Matplotlib

## Основные результаты

- Общая выручка интернет-магазина за исследуемый период составила 9 748 131,07.
- Самый прибыльный месяц — ноябрь 2011 года с выручкой 1 456 145,80.
- Заметный рост выручки с сентября по ноябрь 2011 года.
- На Великобританию (United Kingdom) приходится 84,01% общей выручки интернет-магазина.
- 65,57% покупателей с известным CustomerID совершили как минимум две покупки за исследуемый период.

## Структура проекта

- `pandas_test.py` — Python-скрипт для обработки и анализа данных.
- `report.md` — подробный аналитический отчёт.
- `monthly_revenue.png` — график выручки по месяцам.
- `top10_products.png` — топ-10 товаров по выручке.
- `top10_countries.png` — топ-10 стран по выручке.

## Как запустить проект

1. Скачайте файлы проекта.
2. Установите необходимые библиотеки:

```bash
 pip install -r requirements.txt
```

3. Скачайте датасет [Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail) из UCI Machine Learning Repository и поместите файл `Online_Retail.xlsx` в папку проекта.
4. Запустите анализ:

```bash
 python pandas_test.py
```
